### Selected work

| Project | What it is |
|---|---|
| **[MeshCode](https://www.npmjs.com/package/mesh-code-mcp)** &nbsp;`MCP · npm` | Real-time **MCP server published to npm**, used by other developers. 🥇 1st at JetBrains × OpenAI Codex. |
| **policy-gate** &nbsp;`Go · Systems` | Production Go service that **governs agent tool-calls at ~24k req/s, p99 0.38ms** — a policy layer for what an agent may do, under load. |
| **[RecallOps](https://github.com/Kush614/recallops)** &nbsp;`Agents · Snowflake` | Agent that turns an FDA/supplier recall notice into reviewed, human-approved holds — quoted-evidence extraction, human sign-off, full audit trail. **Tested live on 1,999 real FDA notices — all 15 checks passed.** 🏆 Snowflake × Anthropic. |
| **SIA** &nbsp;`Evals · Self-improving` | Self-improving agent judged by an **ungameable, execution-based eval** — 75.8% → 93.3% on Spider with the model held fixed. |
| **causal-autoresearch** &nbsp;`Verification · RL` | Verification layer (ablation, replication, transfer) that caught a planted exploit passing naive metrics; plus an RL environment (OpenEnv) and LoRA fine-tuning. |
